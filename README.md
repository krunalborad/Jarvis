# 🤖 Jarvis AI - Desktop Voice Assistant

A powerful AI-powered desktop voice assistant built with Python that can perform voice-controlled tasks, automate desktop operations, search the web, interact with AI, control system functions, and provide an animated GUI.

## ✨ Features

- 🎤 Wake Word Detection ("Hey Jarvis")
- 🗣️ Speech Recognition
- 🔊 Text-to-Speech Responses
- 🤖 AI Question Answering
- 🌐 Google Search
- ▶️ YouTube Search
- 📖 Wikipedia Search
- 📰 Latest News
- 🧮 Voice Calculator
- 💬 WhatsApp Message Automation
- 📷 Camera Photo Capture
- 📸 Screenshot Capture
- 🎵 Media Controls
- 🔈 Volume Control
- 🌍 Chrome Browser Automation
- 🖥️ Window Management
- 🎨 Paint Automation
- 🔄 Desktop Refresh
- ⏰ Time Announcement
- 📜 Scroll Up/Down
- ⌨️ Voice Typing
- 💤 Sleep/Wake Commands
- ⚡ Animated GUI
- 🔐 Shutdown & Restart Confirmation

# 🛠️ Technologies Used

- Python 3.x
- SpeechRecognition
- Pyttsx3
- PyAutoGUI
- Tkinter
- Pillow (PIL)
- PyWhatKit
- Requests
- Wikipedia
- RapidAPI
- Threading

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/krunalborad/Jarvis.git
```

```bash
cd Jarvis
```

Install dependencies

```bash
pip install -r requirements.txt
```

If you don't have a requirements.txt file, install manually:

```bash
pip install speechrecognition pyttsx3 pyautogui pillow wikipedia requests pywhatkit pyaudio
```

---

# ▶️ Run

```bash
cd jarvis
python Jarvis_main.py
```
